title: "SeriesFilter"
description: "Narrow a list of series by tournament, team, title, player, time, type, service level, live data, and workflow status."

## Overview

Use `SeriesFilter` in the `filter` argument of the [`allSeries`](/data-apis/central-data/api-reference/queries/allSeries) query to get only the series you need. When you set several fields, a series must match all of them.

Without a filter, `allSeries` returns public and private series, and only series with the workflow status `PUBLISHED`.

## Exclude test series

A filter on title and time alone also returns test series, and the `types` field doesn't remove them. For example, League of Legends series from July 14 to July 19, 2026, with `types` set to `ESPORTS`, include many series from test tournaments such as "LoL unidentified-TEST". These test series have the type `ESPORTS` and are public and published, like real ones.

To get only the series of a real event, filter by the event's tournament: set `tournament.id` to the event's ID and `tournament.includeChildren` to `true`. The example on this page uses this approach.

## Choose between overlapping fields

Some fields are deprecated and have a replacement. Use the replacement, and never set both in the same filter:

- `teamIds` instead of `teamId`. Both return the same series for one team, and setting both makes the query fail with the error "cannot combine two team ID filters, use either teamId OR teamIds".
- `titleIds` instead of `titleId`. Setting both makes the query fail.
- `types` instead of `type`. If you set both, the query uses `type` and ignores `types`.
- `tournament` instead of `tournamentId` and `tournamentIds`. The deprecated fields match only series that belong directly to the given tournaments, so an event whose series are all in child tournaments returns no series.

<ParamField query="tournament" type="SeriesTournamentFilter">
  Filter by the tournament the series is played in.

  <Expandable title="SeriesTournamentFilter fields">
    <ParamField query="id" type="IdFilter">
      Filter by tournament IDs. Set the IDs in `in` (`[ID!]`). On its own, `id` matches only series that belong directly to the given tournaments.
    </ParamField>
    <ParamField query="includeChildren" type="BooleanFilter">
      Set `equals` to `true` to also match series in the child tournaments of the given tournaments. For example, the Esports World Cup 2026 League of Legends tournament (`830107`) returns no series without it and 197 series with it.
    </ParamField>
    <ParamField query="name" type="StringFilter">
      Filter by tournament name. Set `contains` or `equals`. Both are case-insensitive.
    </ParamField>
    <ParamField query="nameShortened" type="StringFilter">

    </ParamField>
    <ParamField query="startDate" type="NullableDateFilter">
      Filter by tournament start date. Set `gte`, `lte`, or both, each a date without a time, such as `2026-07-01`. Both values are included. If both `gte` and `lte` are null, the filter matches tournaments with no start date.
    </ParamField>
    <ParamField query="endDate" type="NullableDateFilter">
      Filter by tournament end date. Set `gte`, `lte`, or both, each a date without a time. Both values are included. If both `gte` and `lte` are null, the filter matches tournaments with no end date.
    </ParamField>

      Filter by the titles of the tournament. Set the title IDs in `id.in`.
    </ParamField>
  </Expandable>
</ParamField>

  <Warning>Deprecated. Use `tournament` instead.</Warning>

<ParamField query="type" type="SeriesType" deprecated>
  <Warning>Deprecated. Use `types` instead, and don't set both.</Warning>

  Filter by one series type.

<ParamField query="types" type="[SeriesType!]">
  Filter by series types. The possible values are the following:

  - `COMPETITIVE`: a competitive series that isn't esports
  - `ESPORTS`: a competitive esports series
  - `LOOPFEED`: a GRID test series played repeatedly in a loop
  - `SCRIM`: a practice series
</ParamField>

<ParamField query="updatedAt" type="DateTimeFilter">
  Filter by the time of the last update to the series. Set `gte`, `lte`, or both, as for `startTimeScheduled`.
</ParamField>

<ParamField query="workflowStatuses" type="[SeriesWorkflowStatus!]!" default="[PUBLISHED]">
  Filter by workflow status. To include deleted series, set `[PUBLISHED, DELETED]`. The possible values are the following:

  - `DELETED`: the series is deleted
  - `PUBLISHED`: the series is created
</ParamField>

## Used by

The `filter` argument of the [`allSeries`](/data-apis/central-data/api-reference/queries/allSeries) query takes `SeriesFilter`. No other query uses it.

<Accordion title="About the example">
  The example gets the series of the Esports World Cup 2026 League of Legends tournament (`830107`) and its child tournaments, scheduled from July 14 to July 19, 2026. It returns the first 2 of 29 series, sorted by start time.
</Accordion>

<RequestExample>
```graphql Query
query SeriesFilterExample($filter: SeriesFilter, $first: Int, $orderBy: SeriesOrderBy!) {
  allSeries(filter: $filter, first: $first, orderBy: $orderBy) {
    totalCount
    edges {
      node {
        id
        type
        startTimeScheduled
        tournament {
          id
          name
        }
      }
    }
  }
}
```

```json Variables
{
  "filter": {
    "tournament": {
      "id": {
        "in": [
          "830107"
        ]
      },
      "includeChildren": {
        "equals": true
      }
    },
    "startTimeScheduled": {
      "gte": "2026-07-14T00:00:00Z",
      "lte": "2026-07-19T23:59:59Z"
    }
  },
  "first": 2,
  "orderBy": "StartTimeScheduled"
}
```
</RequestExample>
